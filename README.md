==================================================

PROJECT PURPOSE

==================================================



GAURGUARD AI is an academic prototype addressing human–wildlife conflict involving wild gaur (Indian bison) in and around Ooty, Tamil Nadu.



The prototype demonstrates how AI-assisted wildlife observation, risk awareness, community reporting and safety guidance could support safer human–wildlife coexistence.



This is NOT a production system.



Use only realistic SAMPLE / DEMO DATA.



Never claim that the application is connected to:

- live cameras

- real-time GPS

- forest department databases

- government APIs

- real-time wildlife feeds

- real-world detection systems



No API keys.

No authentication.

No payment.

No complicated backend.

No external database is required.



Clearly label demo/simulated information throughout the application.
